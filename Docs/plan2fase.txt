Roadmap de Implementação Inteligente: Backend JiukInvest (Arquitetura Avançada)
O objetivo deste roadmap é criar o "Cérebro" do JiukInvest usando LangGraph e FastAPI. Com as novas adições arquiteturais, a solução atingirá não apenas o Nível Especialista (Faixa 4), mas também demonstrará conceitos reais de AML (Prevenção à Lavagem de Dinheiro), Segurança Cognitiva e Prevenção de Alucinações Matemáticas.

Fase 1: Fundação Estrutural e Ferramentas Puras (Tools)
Antes da IA pensar, precisamos dar a ela calculadoras que não erram. O LLM será expressamente proibido de calcular números "de cabeça".

Ferramentas Matemáticas Base (backend/tools/math_tools.py) [NOVO]
Funções isoladas: somar, subtrair, multiplicar, dividir, resto.
Garantirá que qualquer continha básica feita no relatório passe pelo Python, zero margem de erro.
Calculadora Financeira (

backend/tools/financial_calculator.py
)
Função de Juros Compostos e Projeções Futuras de patrimônio.
Catálogo de Produtos (

backend/tools/investment_api_mock.py
)
Classe para ler JSON e buscar produtos usando filtros (Filtro por Risco, Taxa, etc).
Sistema de Blacklist (backend/tools/blacklist_manager.py) [NOVO]
Um script simples em Python para ler/escrever dados infratores num txt (blacklist.txt).
Fase 2: Configuração Cognitiva e LLM Central
System Prompts Avançados (

backend/prompts/system_prompts.py
)
Criação de personas rígidas para: o "Matemático", o "Auditor de Risco", o "Psicólogo Financeiro" e o "Estrategista-Chefe".
Fase 3: A Topologia Multi-Agentes (LangGraph)
Em vez de um único script gigante, teremos Especialistas Reais atuando em cadeia.

1. Etapa de Triagem (Filtro de Barragem)
Estes agentes rodam ANTES de qualquer conselho financeiro ser gerado.

Agente 1: Analista de Contexto e AML (Anti-Money Laundering) - context_analyzer.py
Ação: Avalia as respostas qualitativas do cliente. Se detectar intenções ilegais (Lavagem, Crime), anota na Blacklist.txt e interrompe o fluxo com a mensagem oficial de recusa corporativa. Impede usuários reincidentes consultando a blacklist.
Agente 2: Auditor Demográfico (Age Guardrail) - demographic_auditor.py
Ação: Checa a Idade.
Menor que 13 anos: Redireciona a recomendação para focar na família, saúde mental e estudos no colégio; zero relatórios de aportes.
13 a 16 anos: Foco acadêmico em educação financeira; zero produtos reais recomendados.
Maior de 16: Continua o fluxo normal.
Agente 3: Assessor de Saúde Financeira - financial_health_agent.py
Ação: Valida a realidade. Se aporte_mensal > renda_mensal, barra o processo. Se aporte_mensal > 70% da renda_mensal, adiciona uma "Alerta Forte" na memória indicando que o plano de investimentos final DEVE priorizar a criação de Reserva de Emergência (títulos sem risco) e sugerir moderação no compromisso de renda.
2. Etapa de Estratégia
Agente 4: Estrategista de Alocação (

profile_analyzer.py
)
Ação: Lê os dados de Saúde Financeira, restrições e o contexto do cliente. Usa o 

investment_api_mock.py
 para separar os 5 produtos perfeitos (Ex: CBDs de liquidez diária se precisar de emergência, ou Tesouro se o cara for conservador).
Agente 5: Especialista Matemático (math_specialist.py)
Ação: É um LLM estritamente acoplado às Tools Matemáticas (Fase 1). Ele pega os ativos escolhidos pelo Estrategista e roda todos os cálculos (soma, juros compostos). Retorna os números corretos de volta pro Estado Global.
3. Etapa de Entrega
Agente 6: Redator Chefe (

report_writer.py
)
Ação: Compila a inteligência do Estrategista com os Números Exatos do Matemático. Escreve o Markdown (Resumo e Detalhado), usando tom de voz agradável aos sonhos que o cliente descreveu.
Agente 7: Comitê de Compliance (

compliance_checker.py
)
Ação: Lê o texto final. Tem promessa de retorno nítido em Renda Variável? Tem erro crasso? Se sim, engatilha um Loop de Correção de volta para o Redator Chefe consertar antes de mandar a API responder.
Fase 4: Orquestração LangGraph (

graph_orchestrator.py
)
Mapeamento Nodular condicional. O fluxo será dinâmico:
Frontend -> API -> Context Analyzer.
Se ilegal? Termina (Devolve erro Blacklist).
Se Legal? Vai para Demographic Auditor.
Se Criança? Rota para um redator focado em escola/família.
Se Adulto? Rota para o Fluxo Financeiro (Health -> Strategy -> Math -> Writer -> Compliance).
Fase 5: Integração Frontend e Diferenciais Finais
Rota FastAPI assíncrona recebendo a cadeia.
Exportar o texto final na tela.
Botão PDF: Implementar jsPDF no frontend para baixar o relatório final completo com os selos de análise.
